# Dataset and Model Licences

## Garbage Classification Dataset

- **Source:** https://www.kaggle.com/datasets/mostafaabla/garbage-classification
- **Dataset description:** 12 categories of household waste images.
- **Licence information displayed on Kaggle:** Database: Open Database; Contents: © Original Authors.
- **Important restriction:** The dataset page states that many images were collected from the web and are owned by their original photographers or owners. The database licence should not be treated as blanket permission to redistribute every image.
- **Project handling:** Raw dataset images are stored locally and excluded from Git. Verify the applicable database licence and image-content rights before redistributing the dataset or publishing copies of its images.
- **Dataset attribution:** Credit Mostafa Mohamed and the original dataset source when describing the dataset.

## Model and Code

The classifier code developed for this project is maintained separately from the dataset. Pretrained MobileNetV3-Small weights originate from Torchvision/PyTorch and remain subject to their applicable terms. Review the relevant upstream licence and notices before redistributing model artifacts.

## Current Status

Dataset source and displayed licence information have been recorded. Redistribution rights for individual image contents have not been independently verified.
